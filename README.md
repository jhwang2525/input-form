# Animated Login Form

A sign-in screen with letter-by-letter "wave" labels that float up when a field is focused or filled, plus inline validation and a password visibility toggle.

**Live demo:** https://jhwang2525.github.io/input-form/

![Login form screenshot](screenshot.png)

## Features

- Staggered wave animation on each label letter, generated with JavaScript
- Labels stay raised once a field has a value
- Inline email and password validation with accessible error messages
- Show / hide password toggle
- Split layout with a brand panel that stacks on mobile

## Built with

HTML, CSS and vanilla JavaScript. This is a front-end demo: nothing is submitted anywhere.
